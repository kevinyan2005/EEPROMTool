Sample EEPROM data files for the OneWire EEPROM tool.

SampleEeprom.json     - Example "Open JSON" file. Loadable directly via File > Open.
SampleEeprom_raw.txt  - Example "Open Raw Hex" file: 128 bytes, 16 bytes per line,
                        space-separated hex (matches the app's raw export format).

Both files describe the same DS2431 EEPROM image (Identification, Sensor
Calibration, and User Defined blocks) and can be used to try out the
application without a physical 1-Wire adapter attached.
